## 💻 How to Run Locally

### Option 1: Python HTTP Server (Built-in)
```bash
cd C:\Users\Rakshitha\.gemini\antigravity-ide\scratch\rakshitha-portfolio
python -m http.server 3000
```
Then visit: `http://localhost:3000`

### Option 2: Node.js `npx serve`
```bash
npx -y serve .
```

### Option 3: Direct File
Simply double-click `index.html` to open it directly in any modern browser (Chrome, Edge, Firefox, Brave, Safari).

## 🌐 Free 1-Click Hosting / Deployment

### GitHub Pages:
1. Create a new GitHub repo named `Rakshi0212.github.io` (or `portfolio`).
2. Push all files from `rakshitha-portfolio` to the `main` branch.
3. In repository **Settings** -> **Pages**, select branch `main` and root `/`.
4. Your website will be live at `https://Rakshi0212.github.io`!
